# Completed Projects

## 01-console-basics

Topics:

* Top-level Statements
* Program.cs
* Main()
* Classes
* Properties
* Object Initializers
* Collections
* foreach
* Build / Run / Debug
* VS Code Debugging
* csproj basics

Key Takeaways:

* Program.cs is not the entry point; Main() is.
* A project compiles into a single assembly (.dll).
* .csproj is equivalent to Maven's pom.xml.
* bin/ contains build outputs.
* obj/ contains intermediate artifacts.
